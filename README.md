# 소리 무늬 실험실

중학교 과학 '파동과 소리' 단원용 수업 도구입니다. 진동판 위에 모래를 뿌리고 소리를 들려주면 진동수에 따라 서로 다른 무늬(클라드니 도형)가 나타나는 실험을 시뮬레이션으로 보여 줍니다.

## 바로 쓰기
GitHub Pages 주소로 접속하면 설치 없이 사용할 수 있습니다. 처음 '소리 켜기'를 누르기 전에 음량을 낮춰 주세요.

## 기능
- 소리 발생기: 100~2000Hz 사인파 소리를 실제로 재생하고, 진동수와 음 이름 표시
- 모래 9,000알 시뮬레이션: 많이 흔들리는 곳(배)의 모래는 튕겨 나가고 마디선에 모여 무늬가 생김
- 공명 표시: 공명 진동수 근처에서만 무늬가 뚜렷하게 나타남
- 진동수 자동으로 올리기: 공명 근처에서는 천천히 지나가며 무늬가 차례로 바뀜
- 정사각형 판 / 원형 판 선택
- 공명 진동수 목록(정답) 접어 두기, 원리 설명과 탐구 질문

## 참고
- 무늬 모양은 진동판의 수학 공식(정사각형 판: cos 조합, 원형 판: 베셀 함수)으로 계산합니다. 무늬가 나오는 진동수는 시뮬레이션용 값이며, 실제 판은 재질·두께·크기에 따라 다릅니다.
- HTML 파일 하나로 되어 있어 `index.html`을 내려받아 고쳐 쓸 수 있습니다.
